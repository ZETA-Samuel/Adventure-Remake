# Adventure-Remake
A remake of my previous Adventure Runner.

# You can try it at:
https://zeta-samuel.github.io/Adventure-Remake/

# Objective
Reach the door after collecting the coin without dying.

# HOW TO PLAY
- 'A' and 'D' to move around
- 'W' and 'SPACE' to jump
- 'LSHIFT' to dash
- 'P' to toggle debugger on and off i.e. player's hitbox
- 'Y' to respawn the player if you go off the map
- Do not press 'O' as it closes the game locally but freezes in webpage
